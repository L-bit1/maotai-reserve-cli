# 业务员手机操作指南（无需 Mac / 电脑）

## 真实使用场景

- **业务员**：一部 Android 手机 + 4G
- **管理员**：浏览器打开 Web 管理后台（导入账号、看记录）
- **服务器**：自动维护活动 ID、19:50 备战，**不需要**业务员跑任何脚本

Mac 上的 `phone_connect_check.py`、`pre_20_mobile_go.py` 等仅供**运维调试**，不是用户流程。

---

## 首次使用

1. 浏览器安装 App：http://139.155.134.97/downloads/maotai-reserve.apk
2. 打开 App → **服务器 / 本机编号 / 用户名已自动填好** → 只需输入 owner **密码** 登录
3. **全程保持 Wi-Fi 与移动数据同时开启**，并**关闭个人热点**
4. 登录后 App 会自动 **绑定本机**；首页可再点 **「一键绑定本机」** 确认

## 每天 20 点直购

| 时间 | 手机操作 |
|------|----------|
| 全天 | **Wi-Fi + 移动数据同时开**，热点关 |
| 随时 | **账号** → **待登录** → 每个号 **本机发码 → 登录** |
| 19:50 前 | 首页看 **「20 点直购 · 已就绪」**（服务器也会自动备战） |
| 19:55 | 确认 Wi-Fi + 移动数据均开 → 首页 **「等到 20 点 · 本机直购」**（只点一次，保持前台） |

## 首页状态说明

- **待登录 N**：还有 N 个号没在本机发码登录 → 去账号页
- **可直购 N**：N 个号已就绪，20 点会参与抢购
- **活动 ID**：服务器 19:00 自动更新；也可管理员 Web 改

## 常见问题

| 现象 | 处理 |
|------|------|
| 发码失败 / connection reset | 确认 Wi-Fi + 移动数据均开，热点已关 |
| 可直购 = 0 | 账号页用 **本机发码** 重新登录每个号 |
| 20 点 429 | 通路正常，继续按流程；未抢到是库存/竞争 |

配置写死位置：`src/site_defaults.py`（换服务器/活动 ID 只改这一处）
