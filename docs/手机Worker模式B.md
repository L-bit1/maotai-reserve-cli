# 手机 Worker 模式 B（业务员纯手机操作）

**版本**：v1.0 · 2026-05-27  
**适用**：云服务器 IP 已被 i茅台 429，业务员只用 Android 管理 App 完成 **登录 + 抢酒**。

---

## 架构

```text
业务员手机（4G/5G，关闭 Wi-Fi）
  ├── 直连 i茅台：发码、登录、预约提交
  └── HTTPS → 你们服务器：存 Token、看统计、回写预约结果

服务器：只做数据管理，不向 i茅台 发码/预约（避免 429）
```

与 Mac `local_worker.py` 相同思路，出口改为 **手机蜂窝网**。

---

## 业务员操作流程

### 1. 安装 App

- 浏览器打开：`http://你的服务器/downloads/maotai-reserve.apk`
- 或 Android Studio 编译 `android-app/`（版本 ≥ **1.4.0**）

### 2. 登录管理系统

- 打开 App → 填服务器地址（如 `http://139.155.134.97/api/v1/`）
- 使用 **owner** 密码（与 Web 相同）

### 3. 添加并登录 i茅台 账号

1. **账号** 页 → 添加手机号（或 Web 先导入 CSV）
2. 点 **本机发码**（走手机 4G，不经服务器）
3. 输入短信验证码 → **本机登录**（Token 自动同步到服务器）
4. 编辑收货地址、选店策略

> 建议：**关闭 Wi-Fi，仅使用移动数据**，避免仍走办公室/服务器网络。

### 4. 20 点直购 / 可选 9 点预约

**首页**（App ≥ **1.8.0**）：

| 按钮 | 说明 |
|------|------|
| **等到 20 点 · 本机直购** | **主 KPI**；20:00 + 补货波次，须 4G |
| 立即本机直购 / 直购试跑 | 补跑、配置检查 |
| 等到 9 点 · 本机预约 | 可选抽签，非主 KPI |

**预约** 页也可「本机立即预约 / 本机试跑」。

### 5. 中签与付款

- **中签** 页 → 同步中签 → 让客户打开 **官方 i茅台 App** 付款

## 服务器部署（必须）

更新 API 后重启：

```bash
cd /opt/maotai
# 上传最新 backend + 发布新 APK
sudo systemctl restart maotai-api
```

### 新增接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/mobile/sync-login/{account_id}` | 手机本机登录后写 Token |
| GET | `/api/v1/mobile/worker-bundle` | 拉取已登账号 Token + 商品配置 |
| POST | `/api/v1/mobile/report-reserve` | 回写本机预约结果 |

`POST /accounts/{id}/remote-login` 已对 **owner** 开放（与 Mac 本机脚本共用）。

## 与模式 A 对比

| | 模式 A（服务器+代理） | 模式 B（手机 Worker） |
|--|----------------------|----------------------|
| 发码/登录 | 服务器经代理 | 手机 4G |
| 预约 | 服务器任务 | 手机本机 |
| 需要代理池 | 是 | 否 |
| 1000 号扩展 | 代理池 | 多台手机 / 轮换热点 |

## 限制说明

1. **H5 直购（20:00 平价飞天）**：App ≥ **1.8.0** 首页「等到 20 点 · 本机直购」；商品 `purchase_mode: h5_rush` + `item_priority_act_id`。
2. 单台手机建议 **≤20 个账号** 连续预约，间隔由服务器 `account_stagger_seconds` 下发。
3. App 需保持前台或勿杀进程，等到 9 点任务才可靠执行。
4. 发布 APK：`NEW_VERSION_CODE=5` `./scripts/publish-android-update.sh`
