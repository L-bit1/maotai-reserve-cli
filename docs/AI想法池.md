## 写入模板（复制填空）

**Trae 有新想法时**，在「待处理」加一行，并告诉用户：

```text
我已写入 docs/AI想法池.md 的 T001，请转告 Cursor：
「先读 AI想法池 T001，评估是否实现」
```

**Cursor 有新想法时**，同样写入，用户转告 Trae：

```text
Cursor 建议见 docs/AI想法池.md C001，请 Trae 读并实现或写进 docs/
```

**字段说明**

- **ID**：Trae 用 `T001`、`T002`；Cursor 用 `C001`、`C002`
- **优先级**：P0 今晚 / P1 本周 / P2 可延后
- **想法**：一句话 + 可选「改哪些文件」
