# 本机登录步骤（解决服务器 Web 无法发码）

服务器 IP 被 i茅台 429，**Web「发码/登录」会失败**。请在本机（Mac / 办公室电脑）运行脚本，Token 自动同步到服务器。

## 一、最快方式（Mac）

1. 打开文件夹：`茅台抢单软件`
2. **双击** `启动本机登录.command`
3. 用户名：`owner`
4. 密码：你的 **owner 管理密码**（勿写入公开文档或 GitHub）
5. 对每个号：等短信 → 输入 6 位验证码 → 回车
6. 输入 `s` 跳过当前号；每个号之间自动等 90 秒

## 二、终端方式

```bash
cd "/Users/mac/Desktop/工作 /软件/茅台抢单软件"

# 自检本机能否发码
.venv/bin/python scripts/test_local_vcode.py --mobile 13800000001

# 批量登录全部未登账号
.venv/bin/python scripts/batch_local_login.py --password '你的owner密码'

# 只登 id 1～3
.venv/bin/python scripts/batch_local_login.py --password 'xxx' --ids 1,2,3

# 单号
.venv/bin/python scripts/local_login_to_server.py --mobile 18785006433 --password 'xxx'
```

## 三、登录完成后

1. 打开 http://你的服务器/ → **账号管理**
2. 确认「登录」列为 **已登**
3. 点击 **同步凭证文件**
4. 配置预约任务

## 四、发码失败时

| 现象 | 处理 |
|------|------|
| 429 限流 | 换 **4G 热点**；或等 2 小时；或 `--proxy 'http://user:pass@host:port'` |
| 天启代理 645 | **不要用天启**，本机直连或换其他代理 |
| 已收到短信但发码报错 | 脚本会提示直接输入验证码 |

## 五、办公室电脑 / 轻量云

拷贝整个项目目录，安装依赖后运行 **同一命令** 即可：

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
.venv/bin/python scripts/batch_local_login.py --password 'owner密码'
```

不需要高带宽；关键是 **出口 IP 能发码**（先用 `test_local_vcode.py` 测）。

## 六、1000 号登录（最简单可落地流程）

单机逐个登 1000 号 ≈ **25 小时+**（90 秒间隔），不可行。用下面 **「发码分工 + CSV 一次登录」**：

### 流程总览

```text
① Web 导入 1000 手机号
② 50 个出口 IP 批量发码（每组 20 号）
③ 1000 部手机收短信 → 填 Excel/CSV（mobile,vcode）
④ 本机 CSV 脚本并行登录 → Token 自动上传服务器
```

### 第 1 步：分组（50 组 × 20 号）

```bash
# 服务器或本机，给账号分配 egress_group
python scripts/assign_egress_groups.py --per-group 20
```

在 `config.yaml` 配好 **50 个住宅/4G 代理**（不要用天启固定 IP，i茅台会 645）。

### 第 2 步：批量发码

- **有代理时**：Web → **批量登录** →「批量发码」，间隔 90 秒；或按出口组分 50 次任务（每任务 20 号）
- **无代理时**：10 人分工，每人 ~100 号：

```bash
.venv/bin/python scripts/split_login_shards.py --shards 10 --write scripts/shards/
# 把 scripts/shards/shard_01.command … 分给 10 台 Mac，各自双击运行
```

### 第 3 步：收码填表

导出或自建 CSV（示例 `docs/accounts-login.example.csv`）：

```csv
mobile,vcode
13800138001,123456
13800138002,654321
```

1000 行，一行一号。**发码和填码可以多人并行做。**

### 第 4 步：CSV 一次登录（核心）

```bash
cd "/Users/mac/Desktop/工作 /软件/茅台抢单软件"
.venv/bin/python scripts/csv_local_login.py --csv data/login_codes.csv --workers 10 --interval 2
```

- `--workers 10`：10 线程并行（建议 ≤ 你有的 **不同出口 IP 数**）
- 登录在本机/代理完成，**只把 Token 上传服务器**，不走服务器发码
- 1000 条约 **10～30 分钟** 跑完（视 workers 与网络）

### 人力粗算

| 方式 | 人数 | 耗时（量级） |
|------|------|--------------|
| 10 人分工发码+填 CSV | 10 | 每人 ~100 号，约 2～3 小时 |
| 50 代理自动发码 + 1 人填表 | 1～2 | 发码 ~30 分钟，填表看人手 |
| CSV 脚本登录 | 0（脚本） | 10～30 分钟 |

### 注意

1. **瓶颈是 IP，不是脚本**：1000 号需要约 **50 个不同公网 IP** 发码（每 IP 负责 ~20 号）
2. **天启 645 不可用**，换住宅/4G/其他未封代理
3. Token 过期后：只重登失效号，仍用 CSV 流程
4. 登录完成后：Web **同步凭证文件** → 再跑预约/H5 抢购
