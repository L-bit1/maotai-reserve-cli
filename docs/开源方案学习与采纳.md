## 3. 本次采纳详情

### 3.1 小茅好运专场（ken）

- **开源做法**：`special/session/get` 拉专场，对 `itemList` **全部**商品预约，固定消耗 50 点小茅运。
- **与周末欢乐购区别**：周末用 `getByType/3`，且本仓库只约与 `config.items` 重合的 SKU；小茅好运必须约**整场全部**。
- **本仓库实现**：
  - `IMaotaiClient.fetch_lucky_special_session()` — `src/api.py`
  - `run_lucky_special_reserve()` — `src/extras_runner.py`
  - 定时任务 `lucky_special` — 每月 29 日 20:05（`lucky_schedule`）
  - API `POST /api/v1/lottery/lucky-reserve`
  - CLI 菜单 **11 · 小茅好运专场**

### 3.2 KEN 环境变量导出

```bash
.venv/bin/python scripts/export_ken_env.py
```

输出可粘贴青龙 `KEN_IMAOTAI_ENV`（推荐 `#` 分隔符）。已登录账号 + `config.yaml` 商品列表即可。

### 3.3 Bark 推送（xmtravel）

`config.yaml`：

```yaml
bark_url: "https://api.day.app/你的key"
```

与 PushPlus 并存，`push_notify` / 管理端 `push_if_enabled` 会双通道发送。

### 3.4 定时随机偏移（campus）

`config.yaml`：

```yaml
schedule:
  random_start_offset_max_seconds: 30   # 0=关闭
```

仅影响服务器 `daily_reserve` 启动时刻，降低多实例同秒并发特征。

## 5. 使用建议（结合你当前场景）

1. **登录**：仍走 App 本机 4G 或 `batch_local_login.py`，不要用服务器公网批量发码。
2. **日常 9 点预约**：试点号用 App「等到 9 点」；规模化再 `reserve_execution.mode=server` + 住宅代理。
3. **小茅好运**：每月 29 日 20:05 自动跑；或 Web/CLI 手动触发。
4. **青龙用户**：用 `export_ken_env.py` 导出后，可继续用 ken 的 4/5/8 号脚本作备份通道。

### 7.1 HyggeImaotai 要点

- 面向 **个人 Windows 挂机**：用户管理、预约项目刷新、店铺管理、日志管理四块。
- 选店类型：`1` = 本市出货量最大，`2` = 经纬度最近 —— 对应本仓库 `max_inventory` / `nearest`。
- **不适合你当前 1000 号场景**：无出口池、无 App Worker、无批量登录分流；单机多号易 429/4011。

### 7.2 52pojie 自写工具要点

- `userconfig.json` 示例：`shopIds` 为 **多家门店 ID 按优先级**（`@` 分隔），失败可依次尝试。
- 协议与现网一致：发码 `md5+timestamp`、登录、`actParam` AES-CBC（与本仓库 `src/crypto.py` 相同）。
- 常见坑：`4011 device id inconsistency` —— 登录与预约 **deviceId 不一致**；本仓库 `stable_fingerprint` + 登录写回 `device_ua` 已针对此问题。
- 可选二期：**`shop_id` 支持 `1515@1333@2233` 优先级链**（比 Hygge 的「单店+策略」更细，适合业务员熟悉周边几家店时手工指定）。

### 7.3 campus / CSDN 软文

- Gitee 镜像与 GitHub [campus-imaotai](https://github.com/oddfar/campus-imaotai) 同源，特性已在 §3.4 采纳。
- CSDN 文中「验证码 CNN」「25%–35% 成功率」等 **不可作为工程依据**，核心仍是接口预约 + 选店，无魔法。

### 7.4 综合结论（相对本仓库）

| 维度 | 博客/桌面工具 | 本仓库 |
|------|---------------|--------|
| 1～3 号个人 Windows 挂机 | HyggeImaotai 上手快 | CLI / 本机 Python 亦可 |
| 几十～1000 号 + 分工 | 均不适合 | Web + App Worker + 代理池 |
| 登录 429 | 同样受 EdgeOne 限流 | 本机 4G / `batch_local_login` |
| 设备指纹 4011 | 论坛大量踩坑 | 每号固定 device_id + UA |
| 小茅好运 / 周末专场 | 多数未实现 | ✅ 已实现 + Web 一键 |
| 多店优先级链 | 52pojie 有 | 未实现（**唯一值得二期对齐的选店能力**） |
